# DamienHerlihy Astronomical Website Assets

## Locked masters

These square images are the canonical visual sources. Do not redraw, crop,
colour-grade, overwrite, or replace them when making new website formats.
Always create a separately named derivative.

- `masters/centaur-elt-master.png`
- `masters/star-master.png`
- `masters/constellation-master.png`
- `masters/galaxy-master.png`
- `masters/library-master.png`

## Website banners

## Visual treatment

Use dark indigo-black astronomical paper, warm ivory high-contrast serif type,
muted antique gold accents, fine grain, sparse stars, and generous negative
space. New derivatives must preserve the identity and composition of the
relevant locked master.

The Library master uses a late-1990s beige CRT as an archival search object.
Its unbranded screen contains the exact lowercase query `star`; this screen
text is part of the locked artwork rather than an external title.
